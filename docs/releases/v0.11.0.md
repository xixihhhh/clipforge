# ClipForge v0.11.0

- **逐镜复刻**。在「爆款复刻」上传参考片与商品图，分析后选择「按原片逐镜制作」。素材页会并排显示参考帧与本版画面。选择具体镜头可换商品图、改描述、锁镜，或用支持多图编辑的模型按参考帧重做关键帧。上传、换图和切换版本在本地完成；点击生成会调用已配置的模型。
- **节奏与版本**。原始切点与生成段落分别保留。复制一个版本即可比较 A/B，旧版保留原先选择的素材。已生成或上传的一段视频可以按原切点铺到连续镜头，导出时从对应位置取画面和声音。旁白超过原镜时长会标出镜号。
- **素材与任务恢复**。素材和异步任务与具体脚本、镜头关联。整片云端复刻结果通过服务端保存和恢复，刷新后可继续交付。
