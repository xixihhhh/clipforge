# ClipForge v0.10.0

- **商品图编辑**　使用 OpenAI 图像模型制作整片分镜时，分镜生成现在会收到已上传的商品图和主播参考图，并保留参考图顺序。单张商品照片也可以直接用于编辑。[#46](https://github.com/xixihhhh/clipforge/issues/46)
- **fal.ai 批量生成与任务恢复**　GPT Image 2 的商品图编辑使用 fal 发布的编辑端点。嵌套模型的状态和结果查询使用应用根路径，可用已有任务 ID 查询结果。上游明确拒绝生成时，界面显示失败原因并停止轮询。遇到状态不明的旧任务，请先恢复查询再决定是否重新提交。[#43](https://github.com/xixihhhh/clipforge/issues/43) · [#44](https://github.com/xixihhhh/clipforge/issues/44)
- **GPT Image 2.6 Flare**　在设置中启用 fal.ai 后，可在图像模型中选择 GPT Image 2.6 Flare。纯文字可生成商品主图，附上商品图或主播图时会转为图片编辑。模型由 fal 按用量计费，切换设置本身免费。[fal 编辑接口与计费](https://fal.ai/models/openai/gpt-image-2.6/flare/edit)
- **法语、德语配音和字幕**　在视频配音语言中选择法语或德语，可以翻译旁白、选择对应音色并导出目标语言字幕。Edge 在线音色目录已补齐；本次验证环境请求 Edge 返回 HTTP 403。可使用下方的本机合成方式。[#49](https://github.com/xixihhhh/clipforge/issues/49)
- **可选的本机配音**　法语、德语旁白可交给同一台电脑上的 KittenTTS 2 Mini 合成。下载适配器，按随附 README 安装 Python 依赖、FFmpeg 和模型，再在 ClipForge 设置中选择 KittenTTS。[下载本地配音适配器](https://github.com/xixihhhh/clipforge/releases/download/v0.10.0/clipforge-kitten-tts.zip)
- **MCP**　GitHub Release 随附的 `clipforge-mcp-0.1.7.tgz` 支持新的配音语言。

## English

- **Product reference images.** OpenAI storyboard edits now receive the uploaded product photo and presenter reference in order. A single uploaded product photo also works.
- **fal.ai batches and recovery.** GPT Image 2 sends edits to the published edit endpoint. Queue lookups for nested models use the application root, including when resuming a saved task. Explicit model rejections show the upstream reason and stop polling. Check an existing task ID before submitting again if its status is unknown.
- **GPT Image 2.6 Flare.** Enable fal.ai in Settings and select the optional image model. Use text to create a product photo, or supply reference images to edit it. fal charges for inference according to usage.
- **French and German dubbing.** Select French or German in the video dubbing controls to translate narration and export captions. The Edge voice catalog includes both languages. The Edge service returned HTTP 403 in our test environment. The local KittenTTS option below provides another way to synthesize the narration.
- **Optional local narration.** Run KittenTTS 2 Mini on the same computer to synthesize French and German narration. Download the adapter, follow its README to install the Python dependencies, FFmpeg and model, then select KittenTTS in ClipForge Settings. [Download the adapter](https://github.com/xixihhhh/clipforge/releases/download/v0.10.0/clipforge-kitten-tts.zip)
- **MCP.** The `clipforge-mcp-0.1.7.tgz` GitHub Release asset supports the additional dubbing languages.
