# ClipForge v0.9.12

本次更新修复桌面数据持久化、数据库锁冲突、HTTP 页面报错，并加入 OpenAI 兼容视频接口。

- **重启后保留配置**：桌面设置、品牌、主播、产品和模板改存独立 JSON 文件，不再随本地服务端口变化而丢失。
- **数据库启动恢复**：串行执行数据库迁移，等待临时锁释放；初始化失败后可在下次请求恢复。重复打开桌面应用会回到已有窗口。
- **Docker / 局域网 HTTP**：修复普通 HTTP 地址下上传图片、打开设置及部分编辑操作的 UUID 报错。
- **macOS 窗口恢复**：关闭窗口后再次点击 Dock 图标可重新打开，后台服务保持可用。
- **兼容视频生成**：支持 `/v1/videos` 和显式配置的 `/v1/video/generations` 提交、任务轮询及带鉴权的成片下载。视频写入本地文件，任务可恢复查询；自建模型支持自定义尺寸或省略尺寸。Sora 不支持的时长和尺寸会在提交前提示，避免错误计费。

[兼容视频接口与存储说明](https://github.com/xixihhhh/clipforge/blob/v0.9.12/docs/troubleshooting/desktop-and-video.md)

桌面升级可导入当前浏览器来源的旧配置，但无法自动找回旧版本其他随机端口下的数据。Web/Docker 配置仍保存在浏览器中。

安装包：macOS Apple Silicon（`.dmg`）、Windows x64（`.exe`）、Linux x64（`.AppImage`）。桌面包未签名；首次打开可能需要通过系统的应用安全提示。

---

This release fixes desktop persistence, SQLite startup contention, HTTP LAN access and macOS window reopening, and adds OpenAI-compatible video generation.

Desktop settings and libraries now use atomic JSON files independent of the local server port. Database migrations acquire a write lock before reading migration history, and failed initialization can recover on a later request. HTTP deployments no longer depend on the secure-context-only UUID API.

Video supports the standard multipart `/videos` contract and an explicitly configured JSON `/video/generations` endpoint. Task IDs are saved before polling; authenticated downloads become validated local files. Unsupported Sora duration/size is rejected before submission. Custom models can omit size or provide their own.

Existing data from the current browser origin can migrate automatically; data stored under older random ports cannot be recovered automatically. Web/Docker settings remain browser-local.
