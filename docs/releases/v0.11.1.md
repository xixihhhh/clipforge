# ClipForge v0.11.1

- **工作台与双监看剪辑页**。在源监看里播放当前参考镜头，在节目监看里对照本版素材。下方镜头条支持点选、左右键切镜和时间码定位；桌面右侧检查器集中管理锁定、商品图和镜头描述。素材库、整片生成等批量工具按需展开。

- 复刻项目打开素材页就能对照参考帧、处理当前镜头。用已有商品图可直接进入合成，无需配置生图模型。AI 生图按钮显示目标镜号和模型。
- 切换镜头或版本前会保存正在编辑的描述和商品图，刷新可在当前浏览器会话找回未提交的编辑。用户可以用键盘上传商品图，自动配音开关也能报告状态。
- 从编辑器进入合成会固定脚本版本。下载、导出历史和平台导出选择器会标明已知版本，合成完成后会打开刚刚生成的那条成片。

[工作台截图](https://raw.githubusercontent.com/xixihhhh/clipforge/v0.11.1/docs/releases/images/v0.11.1-workspace.png) · [双监看剪辑页截图](https://raw.githubusercontent.com/xixihhhh/clipforge/v0.11.1/docs/releases/images/v0.11.1-reference-editor.png)

The reference editor now opens before batch generation tools. Use product photos directly with no image model configured, or generate the current shot with the displayed model. Shot and version changes save edits. The export screen keeps the completed render selected and labels known reference versions. Product photo upload and the voiceover toggle support keyboard operation.

The workstation pairs source and program monitors with a timecoded, keyboard-navigable shot timeline and inspector. The home screen now prioritizes your media, recent projects, and creation tasks.
